# Preparación ISTQB CTFL v4.0.1

Curso de estudio en español, organizado en ocho módulos flexibles. Objetivo: comprender, aplicar en QA y responder según ISTQB, aunque no se rinda el examen ahora.

## Para continuar

1. Leer `AGENTS.md`, `ROADMAP.md`, `STUDY_RULES.md` y `PROGRESS.md`.
2. Abrir la siguiente clase indicada en `PROGRESS.md`.
3. Preparar la clase con el syllabus oficial; realizar sus seis pasos; registrar resultados y actualizar el progreso.

El material de las clases es una **guía de preparación**, no clases dictadas ni completadas. Las clases se escriben a medida que se estudian y se verifica cada afirmación contra la fuente.

Fuentes: [syllabus CTFL v4.0.1](https://istqb.org/wp-content/uploads/2024/11/ISTQB_CTFL_Syllabus_v4.0.1.pdf), [descargas y simulacros oficiales](https://istqb.org/certifications/certified-tester-foundation-level-ctfl-v4-0/), [glosario ISTQB](https://glossary.istqb.org/). Este repositorio no redistribuye el PDF ni los exámenes oficiales.
